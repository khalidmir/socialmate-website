# Social Mate Events UAE

Premium events and networking platform connecting professionals, entrepreneurs, and businesses in Dubai and the United Arab Emirates.

## Website Structure

```
├── index.html              # Homepage
├── events.html             # Events listing page
├── networking.html         # Networking page
├── services.html           # Services overview
├── about.html              # About Social Mate
├── contact.html            # Contact & inquiry form
├── privacy.html            # Privacy Policy
├── terms.html              # Terms & Conditions
├── cookies.html            # Cookie Policy
├── css/
│   └── style.css           # Main stylesheet
├── js/
│   └── script.js           # Interactive features
├── assets/
│   └── images/             # Images, logos, icons
├── sitemap.xml             # XML sitemap
├── robots.txt              # Search engine directives
└── _redirects              # Cloudflare Pages redirects
```

## Deployment

This site is deployed on Cloudflare Pages to socialmate.org.

### To Deploy:

1. Push changes to the git repository
2. Cloudflare Pages will automatically build and deploy
3. Verify at https://socialmate.org

## Development

### Making Changes

1. Edit HTML files directly
2. Modify styles in `css/style.css`
3. Add interactive features to `js/script.js`
4. Update sitemap.xml when adding/removing pages

### Adding Images

Place images in `assets/images/` folder:
- Optimize for web (compress PNG/JPG)
- Use descriptive filenames
- Add alt text to all images

### Adding New Pages

1. Create new `.html` file in root
2. Use existing pages as template
3. Update navigation links on all pages
4. Add URL to `sitemap.xml`
